### 🌟 ฟังก์ชันหลักของระบบ (Features)

1. **หน้าแดชบอร์ดภาพรวม (Dashboard):**
   - สรุปตัวเลขสถิติการจองวันนี้, อนุมัติแล้ว, รอการตรวจสอบ/อนุมัติ และจำนวนห้องประชุมทั้งหมด
   - แสดงการ์ดสถานะห้องประชุมแบบเรียลไทม์ (Live Room Status) ว่าห้องใดว่าง หรือมีวาระการใช้งานใดอยู่ในปัจจุบัน
   - ตารางวาระการใช้ห้องประชุมประจำวัน (Today's Agenda)

2. **ระบบปฏิทินการจอง (Calendar View):**
   - แสดงตารางปฏิทินรายเดือนและรายวัน พร้อมระบบรหัสสีระบุสถานะคำขอ (เขียว = อนุมัติแล้ว, ส้ม = รอตรวจสอบ, แดง = ไม่อนุมัติ)
   - ฟิลเตอร์กรองดูเฉพาะห้องประชุมที่ต้องการได้
   - คลิกเพื่อดูรายละเอียดคำขอ และคลิกปุ่ม "+ จองวันนี้" บนช่องวันที่เพื่อเริ่มจองได้ทันที

3. **แบบฟอร์มการจองห้องประชุม (Booking Form):**
   - **ข้อมูลผู้ขอใช้:** ชื่อ-นามสกุล, ตำแหน่ง, หน่วยงาน/สาขาวิชา, หมายเลขโทรศัพท์
   - **วัตถุประสงค์:** ระบุเรื่องและหัวข้อการประชุม/อบรม
   - **ห้องประชุมให้เลือก:**
     1. หอประชุมอดิเรกสาร (~500 ที่นั่ง)
     2. ห้องประชุมสักทอง (~80 ที่นั่ง)
     3. อาคารโดมเอนกประสงค์ (~1,000 ที่นั่ง)
     4. ห้องประชุม (กาแฟ) (~25 ที่นั่ง)
     5. ห้องประชุมหน้าห้องผู้อำนวยการ (~20 ที่นั่ง)
     6. ห้องคอมพิวเตอร์กลาง (ห้องโสต) (~50 ที่นั่ง)
     7. อื่นๆ (ระบุในช่องหมายเหตุ)
   - **กำหนดการ:** วันที่เริ่มต้น - สิ้นสุด, เวลาเริ่มต้น - สิ้นสุด, จำนวนผู้เข้าใช้โดยประมาณ
   - **ครุภัณฑ์และสิ่งอำนวยความสะดวก:** เครื่องฉายภาพ (Projector), ระบบเสียง, ไมโครโฟน, เครื่องปรับอากาศ, อินเทอร์เน็ต/Wi-Fi, โต๊ะ/เก้าอี้เพิ่มเติม, และอื่นๆ
   - **⚡ ระบบป้องกันการจองทับซ้อน (Real-time Conflict Checker):** ตรวจสอบคิวห้องว่างแบบเรียลไทม์ทันทีที่เลือกวันและเวลา หากมีผู้อื่นจองเวลาทับซ้อน ระบบจะแสดงแถบเตือนสีแดงและระงับการส่งฟอร์มทันที

4. **สายการพิจารณาและตรวจสอบ 3 ระดับ (Approval Workflow Hub):**
   - **ระดับ 1 (หัวหน้างาน/ผู้รับรอง):** นายเอกราช เขียวทอง (หัวหน้างานศูนย์ดิจิทัลและสื่อสารองค์กร) - รับรอง / ไม่รับรอง
   - **ระดับ 2 (เจ้าหน้าที่ตรวจสอบห้อง):** นายวัชรพงศ์ โสภา (เจ้าหน้าที่งานศูนย์ดิจิทัลและสื่อสารองค์กร) - ตรวจสอบความพร้อมของห้องและอุปกรณ์ (พร้อมใช้งาน / ไม่พร้อมใช้งาน) พร้อมบันทึกข้อคิดเห็น
   - **ระดับ 3 (ผู้พิจารณาอนุมัติ):** นายชาตรี เริงชัยภูมิ (รองผู้อำนวยการฝ่ายพัฒนายุทธศาสตร์และแผนงาน) - สั่งการ อนุมัติ / ไม่อนุมัติ พร้อมบันทึกข้อสั่งการ

5. **ระบบพิมพ์ใบขอใช้ห้องประชุมราชการ (Official Form Printable):**
   - แปลงคำขอเป็นเอกสารราชการทางการของวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ มีช่องลงลายมือชื่อและตารางรับรองของทั้ง 3 ท่านตามระเบียบ เหมาะสำหรับพิมพ์ออกทางเครื่องพิมพ์หรือเซฟเป็นไฟล์ PDF

6. **ระบบรายงานและสถิติ (Reports & Analytics):**
   - กราฟสถิติสัดส่วนการใช้งานห้องประชุมแต่ละห้อง (Doughnut Chart)
   - กราฟสถิติการใช้งานแยกตามหน่วยงาน/แผนกวิชา (Bar Chart)
   - ค้นหาและกรองข้อมูลตามห้อง หรือสถานะ
   - ปุ่ม **ส่งออก CSV (Excel)** และปุ่ม **พิมพ์รายงานสรุป**

### 🚀 ขั้นตอนการติดตั้งและการนำไปใช้งาน (Step-by-Step Guide)

#### ขั้นตอนที่ 1: เปิด Google Spreadsheet
1. ไปที่ Google Sheet: [https://docs.google.com/spreadsheets/d/1Ap5fdiPYEs8LhEEfAUmQRVaDK9k0D_m_ZyovxPCgk3k/edit](https://docs.google.com/spreadsheets/d/1Ap5fdiPYEs8LhEEfAUmQRVaDK9k0D_m_ZyovxPCgk3k/edit)
2. คลิกที่เมนูด้านบน: **ส่วนขยาย (Extensions) > Apps Script**

#### ขั้นตอนที่ 2: นำโค้ดขึ้น Google Apps Script
1. ที่หน้าต่างโปรเจกต์ Apps Script:
   - เปิดไฟล์ `Code.gs` และลบโค้ดเดิมออกทั้งหมด
   - คัดลอกโค้ดจากไฟล์ `Code.gs` ในโปรเจกต์นี้ไปวางทั้งหมด แล้วกด **บันทึก (Ctrl + S)**
2. คลิกปุ่ม **+ (เพิ่มไฟล์)** ทางซ้ายมือ เลือก **HTML**:
   - ตั้งชื่อไฟล์ว่า `index` (ระบบจะสร้างเป็น `index.html`)
   - คัดลอกโค้ดจากไฟล์ `index.html` ในโปรเจกต์นี้ไปวางทั้งหมด แล้วกด **บันทึก (Ctrl + S)**
3. (ไม่บังคับ) หากต้องการรันเตรียมหัวตารางล่วงหน้า:
   - ในหน้าต่าง `Code.gs` เลือกฟังก์ชัน `initSheets` ที่ดรอปดาวน์ด้านบน แล้วกดปุ่ม **เรียกใช้ (Run)**
   - ให้สิทธิ์การเข้าถึง (Authorize) ในครั้งแรก เพื่อให้สคริปต์สร้างแท็บชีต `Bookings` และ `Rooms` ให้อัตโนมัติ

#### ขั้นตอนที่ 3: เผยแพร่เว็บแอปพลิเคชัน (Deploy as Web App)
1. คลิกปุ่มสีน้ำเงินมุมขวาบน: **การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกที่ไอคอนเฟืองเลือกชนิด: **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** ระบบจองห้องประชุม วท.ท่าหลวงฯ v1.0
   - **ดำเนินการในฐานะ (Execute as):** ฉัน (Me - อีเมลของคุณ)
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone) *(เพื่อให้บุคลากรในวิทยาลัยเข้าใช้งานและส่งคำขอได้สะดวก)*
4. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

#### ขั้นตอนที่ 4: การเปิดใช้งาน
- **วิธีที่ 1 (ใช้งานบน Apps Script):** สามารถแชร์ลิงก์ URL เว็บแอปที่ได้จากขั้นตอนที่ 3 ให้บุคลากรเปิดใช้งานได้ทันทีบนเว็บเบราว์เซอร์หรือมือถือ
- **วิธีที่ 2 (ใช้งานผ่านไฟล์ index.html บนคอมพิวเตอร์):** เปิดไฟล์ `index.html` ในโฟลเดอร์นี้ผ่านเบราว์เซอร์ (Chrome / Edge) แล้วกดไอคอนฟันเฟืองมุมบนขวา นำ URL เว็บแอปไปวาง ระบบจะเชื่อมต่อไปยัง Google Sheets แบบ Real-time ทันที!
